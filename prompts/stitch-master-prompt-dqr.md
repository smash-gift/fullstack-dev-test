# Master STITCH Prompt — AI Gift Card Message Suggester (DQR Tech Palette)

This document contains the **UI Design Master Prompt for STITCH** (Google Stitch UI Builder / AI Prototyping tool), configured with the official color palette extracted from the [DQR Tech](https://www.dqrtech.com.br/) portal and covering the complete Use Cases suite (UC01 through UC10).

## 🎨 Official DQR Tech Color Palette (Design System Tokens)

- **Primary Color (DQR Orange)**: `#FC5C08` (Official DQR Tech vibrant orange)
- **Primary Hover/Active**: `#E04B00` (Burnt orange for active/focused states)
- **DQR Accent Gradient**: `linear-gradient(135deg, #FC5C08 0%, #FF8A00 100%)`
- **Main Dark Background (Dark Mode)**: `#0F0F12` (Dark charcoal/Tech black)
- **Dark Card Surface (Surface Dark)**: `#18181C` (Dark graphite with subtle border `rgba(252, 92, 8, 0.15)`)
- **Light Background (Light Mode)**: `#F8F9FA` (Soft light gray)

- **Secondary Text (Dark Mode)**: `#A1A1AA`
- **Typography**:
  - **Headings & Display**: `Clash Grotesk` (Bold / SemiBold)
  - **Body & Interface**: `Inter` (Regular / Medium)

## 📋 MASTER PROMPT TO COPY & PASTE INTO STITCH

```markdown
Design a complete, high-fidelity Web and Mobile UI prototype for an "AI Gift Card Message Suggester" app built with DQR Tech brand identity.

GLOBAL DESIGN SYSTEM TOKENS (DQR TECH BRANDING):
- Primary Color: #FC5C08 (Vibrant DQR Orange)
- Accent Gradient: linear-gradient(135deg, #FC5C08 0%, #FF8A00 100%)
- Dark Background: #0F0F12
- Card Surface Dark: #18181C with subtle border rgba(252, 92, 8, 0.2)
- Light Background: #F8F9FA
- Card Surface Light: #FFFFFF with soft shadow rgba(252, 92, 8, 0.08)
- Fonts: "Clash Grotesk" for Display/Headings, "Inter" for UI Labels/Body text.
- Border Radius: 16px for Cards, 9999px (Pill shape) for CTAs and Filter Chips.

SCREEN 1: MAIN APP HEADER & OCCASION FORM (UC01, UC02, UC03, UC06)
- AppBar:
  - Left: DQR Tech branded logo "GiftCard AI by DQR" with glowing orange gift icon.
  - Right: Language selector dropdown pill ("🇧🇷 PT | 🇺🇸 EN") and an anonymous guest badge ("👤 Guest Session").
- Hero Banner:
  - Title in Clash Grotesk font: "Create the Perfect Message for Any Gift Card" with vibrant #FC5C08 gradient text.
  - Subtitle: "Generated by Artificial Intelligence in seconds."
- Main Form Card (#18181C in dark mode or #FFFFFF in light mode):
  - Section 1 (Occasion): Label "1. Choose the Occasion" with interactive pill chips: "🎂 Birthday", "💍 Wedding", "🎓 Graduation", "❤️ Love/Dating", "🎄 Christmas", "🙏 Thank You", plus a custom input field.
  - Section 2 (Relationship): Label "2. Who is this card for?" with chips: "Best Friend", "Mother", "Father", "Partner", "Co-worker", "Sibling".
  - Primary CTA Button: Full-width DQR Orange pill button (`background: linear-gradient(135deg, #FC5C08 0%, #FF8A00 100%)`) with white text and sparkling magic icon labeled "Generate Message Suggestions".

SCREEN 2: SHIMMER LOADING & AI GENERATION STATE (UC03)
- Display a sleek loading state while AI generates responses.
- CTA Button transforms into a pulsing loader with text "Crafting personalized AI messages...".
- Show 3 skeleton card placeholders with soft orange glowing shimmer effect (`rgba(252, 92, 8, 0.12)`).

SCREEN 3: SUGGESTIONS RESULT LIST (UC03, UC04)
- Filter Badge Bar: Shows active query "Occasion: Birthday • For: Best Friend".
- Result Cards List: Display 2-3 generated gift card message options.
  - Each Card (#18181C) features quotes, elegant line height, and a bottom action bar:
    - Action 1: "📋 Copy Text" button (shows Toast notification "Copied!").
    - Action 2: "🔗 Share" button (opens native share modal).
    - Action 3 (Prominent CTA): "🎨 Design Visual Card" button with orange border and wand icon.
- Bottom Action: "🔄 Generate New Suggestions" button.

SCREEN 4: VISUAL GIFT CARD CANVAS EDITOR & DEDICATION (UC07, UC08, UC09)
- Top Navigation: Back button, Header "Visual Card Editor", and Top-Right "Download / Share" CTA button in #FC5C08.
- Main Workspace: High-definition vertical gift card preview canvas (9:16 aspect ratio):
  - Custom Dedication Overlay: "To: Ana" at top, AI message body in elegant serif font, "From: Lucas • With love" at bottom.
  - Background Theme: Option to toggle pre-made visual themes ("Festive Birthday", "Elegant Minimalist", "Romantic Floral", "DQR Tech Gold").
- Bottom Tool Tabs:
  - Tab 1 (Visual Themes): Visual thumbnails for background styles.
  - Tab 2 (To/From Dedication): Inputs for Recipient Name ("To"), Sender Name ("From"), and custom memory note.
  - Tab 3 (Typography): Font style toggles (Handwritten, Classic Serif, Modern Sans) and alignment controls.
- Export Modal (Triggered by "Download"):
  - Option A: "📱 Save PNG Image (HD for WhatsApp/Instagram)".
  - Option B: "🖨️ Generate Foldable PDF Card (Printable A4)".

SCREEN 5: SAVED CARDS GALLERY (UC10)
- Accessible via "⭐ My Saved Cards" tab.
- Responsive grid view displaying saved gift card designs with instant copy, edit canvas, or delete options.

SCREEN 6: SERVICE UNAVAILABLE 503 FALLBACK CARD (UC05 - RN04)
- Friendly error card with soft orange warning border.
- Friendly message: "The AI service is temporarily unavailable. Please try again in a few moments."
- CTA Button: "Try Again (Retry)" in DQR Orange #FC5C08.
```
